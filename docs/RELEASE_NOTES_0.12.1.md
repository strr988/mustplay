# mustplay v0.12.1 — улучшения интерфейса и надёжности

Обновление десктопного музыкального плеера для **Windows x64**. Версия 0.12.1 объединяет изменения UX & Reliability, внесённые после публичного выпуска v0.11.0. Отдельный выпуск v0.12.0 не публиковался.

## Что нового

- **Единые настройки.** Шесть разделов: «Внешний вид», «Воспроизведение», «Источники и подключения», «Импорт и файлы», «Модули и инструменты», «О приложении». Переход из импорта и поиска открывает нужный раздел.
- **Удобнее импорт и поиск.** Ясные состояния подключения и ошибок, настройка папки загрузки, история заданий, отмена и повтор неудачных операций, фирменные иконки сервисов.
- **Тексты песен.** Отдельная панель чтения с обложкой и переход в полноэкранную «Текстомузыку» с синхронизированными строками; автоматическая прокрутка временно приостанавливается при ручной навигации.
- **Полировка плеера.** Обновлены элементы управления темой, масштабом, звуком, пульсацией «Моей волны» и диско-эффектом, в том числе поведение при ограничении анимаций.

## Надёжность и безопасность

- **Проверенные инструменты.** `yt-dlp` и `fpcalc` загружаются из закреплённых версий с ограничением размера и проверкой SHA-256.
- **Безопасность токена Яндекс Музыки.** Для сохранения нового токена требуется системное шифрование; при его отсутствии запись отклоняется. Заголовок авторизации не передаётся сторонним CDN.
- **Загрузки без перезаписи.** Улучшены потоковая обработка и запись тегов, реакция на ошибки и отмену, обработка совпадающих имён файлов и LRC.
- **Обложки и метаданные.** Оптимизирована обработка MP4/M4A с большими аудиоданными.
- **Миграция профиля.** Схема SQLite **16**, тесты на исторических профилях 0.8.0, 0.9.0-yandex и 0.10.0, проверка резервных копий и восстановления.
- **Windows release smoke-тесты.** Добавлены тесты установки и переносимости ZIP, Unicode-путей и защита от кратковременной блокировки файлов после закрытия приложения.

## Установка на Windows

1. Скачайте файл `mustplay-0.12.1-win-x64.zip` из Assets этого выпуска.
2. Сверьте SHA-256 с `mustplay-0.12.1-win-x64.zip.sha256` (например, PowerShell: `Get-FileHash .\mustplay-0.12.1-win-x64.zip -Algorithm SHA256`).
3. Распакуйте архив полностью и запустите `mustplay.exe` из папки `mustplay 0.12.1`. Установка не требуется.
4. Данные библиотеки находятся отдельно от приложения в профиле Windows. **Перед обновлением рекомендуется сохранить резервную копию профиля и пользовательских файлов.** При обновлении библиотека мигрирует на схему 16.

Работа с внешними музыкальными сервисами зависит от их доступности, правил и наличия прав на используемые записи. Для скачивания через Яндекс Музыку нужны личный токен и подходящая подписка. macOS и Linux в этом выпуске не проверены.

**Полная история изменений:** [CHANGELOG.md](https://github.com/strr988/mustplay/blob/main/CHANGELOG.md).

**Примечание о дистрибутиве:** Windows ZIP не подписан сертификатом издателя; при первом запуске Windows может показать предупреждение SmartScreen. Проверьте лицензионные уведомления сторонних компонентов до публичного распространения.
